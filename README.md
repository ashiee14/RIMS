# RIMS – Research Information Management System

A modern web-based platform for managing and analyzing institutional research data.

## 🚀 Features
- Publications & Research Management
- Research Project Tracking
- Journal Checker & SDG Tagger
- Research Analytics Dashboard
- Aurora-Themed UI
- Add/View Research Modules

## 🛠️ Tech Stack
- React (Vite)
- JavaScript (ES6+)
- React Router
- HTML5 & CSS3
- Git & GitHub

## 📦 Installation
```bash
git clone https://github.com/ashiee14/RIMS.git
cd RIMS
npm install
npm run dev
